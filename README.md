今天学的这些基本上是由**红黑树**构成的
特别注意红黑树的**五个规则**
- **节点颜色**规则：每个节点要么是红色，要么是黑色，不存在其他颜色。
- **根节点**规则：红黑树的**根节点必须是黑色**。
- **叶子节点**规则：所有**叶子节点**（即**空节点NIL**）都是**黑色**。
- **红色节点**规则：红色节点的父节点和子节点必须是黑色，即**红节点不能相邻**。
- **黑高**规则：从任意节点到其所有后代叶子节点的路径中，包含的**黑色节点数量相同**（该数量称为“黑高”）

### 第二十四天
- **Exception**

包含**抛出异常** **处理异常** **自定义异常**
其实和**cpp的异常机制**差不多
都是**try->catch->throw**
**throws**用于在**方法签名处**声明可能抛出的异常类型
核心作用是将异常处理责任转移给**上层调用者**
**本身不会处理异常**
当方法内部调用了可能抛出**受检异常**的代码
且没有使用 **try-catch** 捕获时
编译器会**强制**要求添加 **throws 声明**
否则**编译失败**
常见受检异常：**IOException SQLException ParseException**
需要编译器强制校验处理逻辑
