### 第十一天
学习了**final关键字**和**代码块**
**抽象类**和**抽象方法**
final正如他的意思一旦确定就不能更改
主要是**static代码块**
随着类的构造而调用
可以用来初始化一些信息
还有**抽象类**和**抽象方法**
抽象类不一定有抽象方法
但是**有抽象方法一定是抽象类
抽象类的子类一定要重写父类的抽象方法
或者说本身也写成抽象类**

### 第十二天
学习了**接口**
接口设计是为了方便特定的类去使用一些相同的方法
**接口里面默认是抽象方法
接口也是不能被初始化的**
如果是**abstract方法** 调用者要重写方法
还可以写**private**和**static**
static用接口名去调用
接口也是可以**继承**的
如果一个接口设计了很多方法
但是调用类只想要调用一个
就可以设计**适配器设计模式**
简单来说就是用**空类**就重写空方法
该类继承即可

### 第十三天
学习了**内部类**和**md文件**的一些操作
内部类分为**成员** **静态** **局部** **匿名**
其中局部内部类了解即可
注意成员内部类和静态内部类的**构造方法**
这两类都可以访问**外部类**的成员
外部类要访问内部类的成员需要**实例化对象**
可以做为参数直接传给method(方法)
匿名内部类主要是为了在**实现类**
只需要实现较少次数时用于简化代码
